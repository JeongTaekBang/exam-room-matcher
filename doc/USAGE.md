# 강의실 배정 프로그램 — 사용 가이드

처음 쓰거나 오랜만에 다시 쓸 때 보는 문서. 데이터 준비 → 실행 → 5탭 작업 흐름 → 내보내기까지의 순서를 담았다.

---

## 1. 실행

```bash
# Windows
run.bat  (더블클릭)

# 또는 직접
streamlit run dashboard.py
```

처음이라면 의존성 설치부터:

```bash
pip install openpyxl streamlit pandas pytest
```

브라우저가 자동으로 열리고 대시보드가 뜬다.

## 2. 데이터 준비

`{년도}/{학기}_{시험종류}/` 폴더에 엑셀 2개를 넣어두면 자동으로 인식된다.

```
exam_room_matcher/
└── 2026/1학기_중간고사/
    ├── *요청사항*.xlsx     ← 시험 요청 (강의실 선택 / 시험일자 / 요청사항 등)
    └── *타임테이블*.xlsx   ← 기존 강의실 시간표 (시트 이름 = "4.21.(화)")
```

### ⚠ 파일명 규칙 (중요)

파일명에 다음 키워드가 **정확히** 들어가 있어야 인식된다:

| 파일 종류 | 필수 키워드 | OK 예시 | NG 예시 |
|---|---|---|---|
| 시험 요청 | **`요청사항`** | `B 2026-1 중간고사 요청사항 ...xlsx` | `B 2026-1 중간고사 요청.xlsx` |
| 강의실 시간표 | **`타임테이블`** | `2026-1학기 강의실 타임테이블.xlsx` | `2026-1학기 강의실 **시간표**.xlsx` |

폴더에 파일은 있는데 사이드바 "데이터 선택" 드롭다운에 폴더가 안 보인다면 대부분 이 케이스. 특히 학교에서 받은 시간표 파일이 "시간표"라고 되어 있으면 **"타임테이블"로 리네임**해야 한다.

> 키워드 검사는 부분 매칭이므로 파일명 앞뒤에 추가 텍스트(연도/학기/담당자명 등)가 있어도 무방하다. `~$`로 시작하는 임시 파일은 자동 제외.

### 시트 이름 규칙

타임테이블 엑셀의 시트 이름은 `M.D.(요일)` 형식이어야 한다 (예: `4.21.(화)`, `6.16.(화)`). 이 패턴이 안 맞으면 날짜·요일 매핑이 안 만들어져서 빈 시간표로 로드된다.

대시보드 사이드바에서 **년도 / 학기·시험종류**를 선택하면 해당 폴더가 로드된다.

> 결과 파일(`_assignments.json`, `_releases.json`, `_assignment_audit.jsonl`)은 작업 중 자동으로 같은 폴더에 생성된다.

## 3. 작업 흐름 — 5탭 순서대로

### 탭 1: 기존 시간표 (AS-IS)
원본 강의실 시간표를 격자로 본다. 갈색/청록 색상은 엑셀 원본 셀 색상을 그대로 보존한 것.

### 탭 2: 배정 작업 ★ 핵심 탭
운영자가 가장 오래 머무는 탭. 미배정 과목을 하나씩 처리한다.

작업 순서:
1. **진행 요약** — 전체 / 자동해제 / 배정완료 / 미배정 건수 확인
2. **필터/검색** — 분류·요일·교시·키워드로 좁히기
3. **잔여 슬롯 히트맵** — 어느 교시·강의실이 비었는지 한눈에
4. **수급 현황** — 시간대별 공급(빈 강의실) vs 수요(미배정 과목)
5. **미배정 과목 선택** → **배정 방식 선택** → **빈 강의실 선택** → **배정**
   - **이동**: 다른 강의실로 옮김
   - **분반**: 추가 강의실로 쪼개 배정 (+N 키로 다중 배정)
     - 기존 강의실 유지 / 기존 미유지 두 가지
   - **기존 강의실 유지**: 그대로 둠
6. **해제**: 자동해제 대상은 알아서 처리됨. 추가로 손으로 해제할 수도 있음
7. **점유 현황 격자** — 현재 배정 상태
8. **작업 현황** — 방금 한 작업 확인

> **자동 해제**는 손댈 필요 없음:
> - 미실시(NO_EXAM) → 전체 교시 해제
> - 강의실 이동(ROOM_CHANGE) → 원래 강의실 해제
> - 부분 교시(NORMAL_EXAM, 시험교시 < 수업교시) → 미사용 교시 해제

### 탭 3: 배정 현황
- **검수 큐** — 부분 해제 확인 필요 등 검토할 항목
- **완료 목록** — 배정 끝난 과목
- **내보내기** — 엑셀/CSV 다운로드
- **이력** — 작업 감사 로그

### 탭 4: 결과 검증 (TO-BE)
요청 + 배정을 오버레이한 최종 그림.

색상 의미:
- 🔴 **빨강** — 충돌 (같은 강의실+교시에 2개+ 과목)
- 🩷 **핑크** — 자동 해제됨
- 🟢 **초록** — 시간표 외 강의실 (수업시간표에는 있지만 타임테이블 엑셀에 없는 강의실)

**빨간 셀이 없을 때까지 탭 2로 돌아가서 조정**하는 게 마무리 기준.

### 탭 5: 통계
분류별 / 일별 / 강의실 가동률.

## 4. 핵심 개념 (요약)

- **자동 배정 없음** — 사람이 직접 하나씩. 프로그램은 **시각화 + 충돌감지 + 자동해제** 전용
- **5개 분류** — NORMAL_EXAM / NO_EXAM / ROOM_CHANGE / ROOM_SPLIT / SKIP
- **분류 근거** — N열(강의실선택) + K열(시험일자) + O열(요청사항 키워드)
- **요청사항 텍스트는 원문 그대로** 표시. 단 미실시 판정 시 "미실시"·"대체과제" 등 사전 정의 키워드 매칭
- 결과는 JSON 파일에 **원자적 저장** + **mtime 비교**로 동시 작업 보호

### 자동 완료 vs 수동 배정

전체 시험 중 대부분은 운영자가 손댈 필요 없이 자동으로 "완료" 처리된다. 진짜 작업해야 하는 건 **ROOM_CHANGE / ROOM_SPLIT**뿐.

| 분류 | 상태 | 운영자 작업 |
|---|---|---|
| **NORMAL_EXAM** (시험 진행) | 자동 **완료** | 없음 (기존 강의실 그대로). 시험교시 < 수업교시면 자동 부분해제 |
| **NO_EXAM** (미실시) | 자동 **완료** | 없음. 전체 교시 자동 해제 → 빈 슬롯 풀로 환원 |
| **ROOM_CHANGE** (강의실 변경) | **미배정** | 새 강의실 직접 지정 (원래 강의실은 자동 해제됨) |
| **ROOM_SPLIT** (분반) | **미배정** | 추가 강의실 직접 지정 (+N 키로 다중) |
| **SKIP** (미확정) | **미확정** | 정보 부족 — 검토 필요 |

탭 2 진행 요약 지표:
- **자동해제** = NO_EXAM + ROOM_CHANGE 원래 강의실 + NORMAL_EXAM 부분교시
- **배정완료** = 위 자동 완료분 + 운영자가 직접 배정한 건
- **미배정** = ROOM_CHANGE/ROOM_SPLIT 중 아직 새 강의실 안 잡힌 것

> "미배정 N건"이 전체 시험 수보다 훨씬 적게 보여도 정상. 대부분이 NORMAL_EXAM이라 이미 완료로 잡혀 있어서임.

### 검수 큐 — 상태와는 별개의 "확인 필요" 차원

탭 2/3에 보이는 **검수 큐** 카운트는 완료/미배정/미확정 합계와 무관하다. **상태 분류와는 독립된 별도 차원**으로, "추가 확인이 필요한 항목"만 따로 모은 것.

```
완료 + 미배정 + 미확정 = 전체   (상태 — 서로 배타)
검수 큐                          (이슈 — 위와 독립, 중복 가능)
```

즉, **자동 "완료" 처리된 NORMAL_EXAM이 검수 큐에 들어가는 경우도 있다.**

#### 검수 큐 진입 조건 (5가지)

| 트리거 | 대상 분류 | 이슈 표시 |
|---|---|---|
| 1. SKIP 자체 | SKIP | 분류 미확정 |
| 2. 시험일자가 매핑에 없음 | NORMAL/CHANGE/SPLIT | 시험일자 누락/범위 밖 |
| 3. 시험교시 정보 없음 | NORMAL/CHANGE/SPLIT | 시험교시 정보 없음 |
| 4. **부분해제 확인 필요** | **NORMAL_EXAM** (시험교시 미명시 + 수업 2교시 이상) | 수업 X교시, 시험교시 미명시 → 수동 해제 필요 |
| 5. 배정 후보 없음 | CHANGE/SPLIT 미배정 | 빈 강의실 0 |

#### 검수 큐가 클 때 — 4번이 주범일 가능성

기말고사처럼 검수 큐가 200건 이상으로 크게 나오면 보통 **4번 "부분해제 확인 필요"** 가 대부분이다.

NORMAL_EXAM은 분류 단계에서 자동 완료지만, **시험교시 명시가 없으면서 수업이 2교시 이상**이면 프로그램이 어느 교시를 부분해제해야 할지 판단할 수 없다 → 검수 큐로 빠진다. 운영자가 직접 "이 과목은 X교시만 시험본다"는 정보를 확인해서 수동 해제해야 한다.

탭 2 진행 요약의 "완료" 옆 help 텍스트에 "이 중 N건이 검수 큐에 있습니다"라고 뜨는 것도 같은 이유 — 완료 카운트와 검수 큐가 겹친다는 표시.

#### 대응 순서

1. **탭 3 → 검수 큐 표의 "이슈" 컬럼**으로 분포 확인
2. "분류 미확정"·"시험일자 누락"·"시험교시 정보 없음" → 요청사항 엑셀 원본 점검 (데이터 누락 또는 표기 오류)
3. "부분해제 확인 필요" → 요청자에게 시험교시 확인 → 탭 2에서 해당 강의실의 미시험 교시 수동 해제
4. "배정 후보 없음" → 같은 시간대에 자동해제된 강의실 풀어 쓰거나, 시험 시간 조정 협의

산수·로직 자세히 보려면 → [MATH_GUIDE.md](MATH_GUIDE.md) 또는 인터랙티브 [MATH_VISUAL.html](MATH_VISUAL.html)

## 5. 자주 묻는 상황

**Q. 같은 과목을 두 강의실로 쪼개고 싶다**
→ 탭 2 → 분반 선택 → 첫 번째 강의실 배정 → **+N 키**로 추가 강의실 배정

**Q. 빨간 셀(충돌)이 나왔다**
→ 탭 4에서 어느 교시·강의실이 겹쳤는지 확인 → 탭 2에서 한쪽을 이동

**Q. 자동 해제된 강의실을 다시 쓰고 싶다**
→ 자동 해제 항목은 빈 강의실 풀로 반환됨. 탭 2 빈 강의실 선택에서 그대로 사용 가능

**Q. 다른 사람이 동시에 작업했다**
→ 저장 시 "외부 변경 감지" 경고 → **새로고침** 후 다시 작업 (작업 손실 방지)

**Q. 전체 초기화하고 싶다**
→ 사이드바 체크박스 확인 후 버튼 활성화 (오클릭 방지)

## 6. 트러블슈팅

- **한글 경로에서 인코딩 에러** → `python -X utf8 -m pytest ...` 처럼 `-X utf8` 사용
- **사이드바에 폴더가 안 보임** → 폴더 안 파일명에 "요청사항"·"타임테이블"이 들어있는지 확인. 학교에서 받은 시간표 파일이 **"시간표"**로 되어 있다면 **"타임테이블"로 리네임** 필요. 자세히는 [§2 파일명 규칙](#2-데이터-준비) 참고
- **타임테이블 시트는 로드됐는데 모든 강의실이 비어 보임** → 시트 이름이 `M.D.(요일)` 형식인지 확인 (예: `4.21.(화)`). 다른 형식이면 매핑 생성 실패
- **다주차 시험에서 자동 해제가 한쪽에만 적용** → 해결됨. NO_EXAM 자동 해제는 `day_to_sheets`(1:N)를 사용해 같은 요일의 모든 시트에 적용된다. 일반 배정/해제는 항상 요청서의 `시험일자`로 시트가 결정되므로 다주차 영향 없음
